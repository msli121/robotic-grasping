1. 自制的抓取实验对象的目标检测数据集
- custom是数据集名称
- images是数据集图片
- labels是数据集标签
- classes_zh.txt是数据集对应的所有类别

2. 使用X-AnyLabeling工具标注数据集
https://github.com/CVHub520/X-AnyLabeling

3. 自定义数据集文件夹要求
custom/
├── images/
│   ├── train/      # 训练集图片
│   ├── val/        # 验证集图片
│   └── test/       # 测试集图片（可选）
├── labels/
│   ├── train/      # 训练集标签
│   ├── val/        # 验证集标签
│   └── test/       # 测试集标签（可选）
├── data.yaml       # 数据集的配置文件

4. 标签文件格式（YOLO格式）
<class_id> <x_center> <y_center> <width> <height>
说明：
class_id: 目标的类别 ID（从 0 开始编号）
x_center: 目标中心的 x 坐标（相对于图片宽度的比例，值在 0 到 1 之间）
y_center: 目标中心的 y 坐标（相对于图片高度的比例，值在 0 到 1 之间）
width: 目标的宽度（相对于图片宽度的比例，值在 0 到 1 之间）
height: 目标的高度（相对于图片高度的比例，值在 0 到 1 之间）
示例：
0 0.5 0.5 0.25 0.25
1 0.3 0.3 0.1 0.1

5. 训练集、验证集和测试集的区别
训练集（Train Set）：模型训练使用的数据集，用于调整模型的参数（权重）。训练集中包含标注的图像以及对应的标签文件。
验证集（Validation Set）：用于在训练过程中评估模型的性能，帮助调整模型超参数，避免过拟合。验证集的数据不会用于训练，只用于评估模型的表现。
测试集（Test Set）：模型完全训练好之后，用于最终评估模型的泛化能力，通常用来衡量模型在实际场景中的表现。测试集的数据与训练和验证数据完全独立。
通常，数据集按 8:1:1 的比例划分为训练集、验证集和测试集。
